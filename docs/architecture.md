# 구조

```text
src/domain        시간, 예산, 랭킹, 마을, 검증. UI와 DB가 없는 순수 규칙
src/server/engine 데모와 단위 테스트가 쓰는 상태 기계
src/server/data.ts 데모 파일 또는 Supabase를 고르는 서버 API
supabase/migrations 운영 PostgreSQL 제약, RLS, 금액 함수
src/app           한국어 모바일 화면
```

화면 순서는 짧은 머리글, 오락실 검색, 지도, 이번 주 예산, 마을 미리보기, 랭킹, 복수, 최근 인형, 최근 활동, 하단 이동입니다.

금액 계산과 순위 계산은 `src/domain`에 한 번 있습니다. 운영 모드의 쓰기 확인은 SQL 함수가 다시 하고, 읽기 집계도 SQL이 비공개 금액을 뺀 뒤 같은 랭킹 함수에 넘깁니다. 두 구현의 지문 문자열이 같을 필요는 없고, 각 경로 안에서는 저장 직전에 다시 계산한 지문만 인정합니다.

마을 캔버스는 Phaser를 쓰지 않습니다. 격자 길찾기와 `requestAnimationFrame`이며, 언마운트 때 루프와 이벤트를 제거합니다. 픽셀 이미지가 없으면 기하학적 기본 캐릭터를 그립니다.

인형뽑기 기계 미니게임은 구현하지 않습니다. 화면에 “추후 업데이트”만 있습니다.
